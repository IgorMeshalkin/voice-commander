# Voice Commander

Voice Commander — локальный помощник для работы с голосом. Он помогает быстро надиктовывать текст, сохранять важные разговоры и превращать записи в понятные заметки и задачи.

## Возможности

- **Голосовой ввод для терминала и других приложений** — надиктуйте текст, и он сразу попадёт в буфер обмена.
- **Запись и сохранение аудио** — записывайте системный звук и микрофон, не отвлекаясь от работы.
- **Управление записями** — находите, прослушивайте, переименовывайте и удаляйте сохранённые файлы через веб-интерфейс.
- **AI-ревью записей** — получайте краткий разбор содержания, основные мысли и полезные выводы.
- **Задачи на основе записей** — создавайте задачи из результатов ревью, указывайте сроки и следите за их статусом.

## Системные требования

Для записи микрофона и системного звука нужен `ffmpeg`:

```bash
sudo apt-get update && sudo apt-get install -y ffmpeg
```

Без него горячая клавиша записи сработает, но аудиофайл не будет создан.

## Горячие клавиши

- **Удерживать `Ctrl + Space` 1 секунду** — начать распознавание речи. Отпустите клавиши, и распознанный текст попадёт в буфер обмена.
- **Удерживать `Ctrl + Space + S` 1 секунду** — начать запись микрофона и системного звука.
- **Нажать `Ctrl + Space` во время записи** — остановить и сохранить запись.
- **`Ctrl + Y`** — вставить фразу «Да».
- **`Ctrl + U`** — вставить фразу «Нет».
- **`Ctrl + I`** — вставить фразу «Согласовано, делай».
- **`Ctrl + H`** — вставить фразу «Готово».
